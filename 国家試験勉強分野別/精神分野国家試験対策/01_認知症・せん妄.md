# 認知症・せん妄

## 最初に覚える

- 認知症では、脳機能障害から直接生じる**中核症状**と、環境や身体状態にも左右される**BPSD**を分ける。
- 中核症状は記憶障害、見当識障害、実行機能障害、失語、失行、失認などである。
- BPSDは幻覚、妄想、徘徊、興奮、抑うつ、無気力、睡眠障害などである。
- 認知症で最も多いのはAlzheimer型認知症である。

## 認知症の見分け方

| 疾患 | 国試で重要な特徴 |
|---|---|
| Alzheimer型 | 近時記憶障害から緩徐に進行する。取り繕いがみられる |
| Lewy小体型 | 認知機能の変動、具体的な幻視、Parkinson症状、REM睡眠行動障害、自律神経症状 |
| 血管性 | 脳血管障害に対応し、段階的・まだら状に悪化しやすい |
| 前頭側頭型 | 早期から脱抑制、常同行動、人格・社会行動の変化が目立つ |
| 正常圧水頭症 | 歩行障害、認知機能低下、尿失禁。手術で改善する可能性がある |

- Lewy小体型では後頭葉の血流低下が特徴になる。
- 認知機能の変動と幻視があれば、Alzheimer型よりLewy小体型を考える。
- 脱抑制や人格変化が早期から目立てば、前頭側頭型を考える。
- 正常圧水頭症と慢性硬膜下血腫は、治療で認知機能が改善し得る。

## HDS-RとMMSE

- HDS-Rには年齢、日時・場所の見当識、3語記銘、遅延再生、数字の逆唱、物品記銘、野菜名の流暢性が含まれる。
- MMSEには計算、復唱、3段階命令、読字、書字、図形模写が含まれる。
- 「文章を書く」「図形を模写する」はMMSEに特徴的である。
- 「野菜名をできるだけ多く言う」「数字を逆から言う」はHDS-Rに含まれる。
- 点数だけで診断せず、教育歴、失語、視聴覚障害、疲労の影響も考える。

## せん妄との違い

| 項目 | せん妄 | 認知症 |
|---|---|---|
| 発症 | 急性 | 多くは緩徐 |
| 経過 | 日内変動が大きい | 徐々に進行 |
| 注意 | 著しく低下 | 初期は比較的保たれることがある |
| 意識 | 変動・混濁する | 通常は清明 |
| 可逆性 | 原因治療で改善し得る | 原因による |

- 高齢、入院、感染、脱水、薬剤、手術、睡眠不足はせん妄の危険因子になる。
- 夜間に悪化しても、せん妄が夜間だけに起こるとは限らない。
- せん妄では睡眠覚醒リズムが乱れ、見当識や認知機能も低下する。

## 国試のひっかけ

- 幻視があるだけで統合失調症と決めない。高齢者で認知機能の変動とParkinson症状があればLewy小体型を考える。
- BPSDは記憶障害そのものではない。
- 認知症はすべて不可逆的とは限らない。治療可能な原因を忘れない。
- 難聴がある人に、聞こえない距離から質問して認知機能を判断しない。

## 直前チェック

- Alzheimer型＝最も多い、緩徐進行
- Lewy小体型＝幻視・変動・Parkinson症状
- 前頭側頭型＝脱抑制・常同行動
- せん妄＝急性・変動・注意障害
- HDS-R＝数字逆唱・野菜名
- MMSE＝書字・図形模写

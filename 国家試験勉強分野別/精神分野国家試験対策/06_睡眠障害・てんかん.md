# 睡眠障害・てんかん

## てんかん発作の分類

- 焦点意識保持発作では意識が保たれる。
- 焦点意識減損発作では意識が障害され、自動症や徘徊がみられることがある。
- Jackson発作は焦点運動発作で、意識が保たれることがある。
- 欠神発作は短い意識消失が反復し、典型例では3 Hz棘徐波複合がみられる。
- ミオクロニー発作は、瞬間的な筋収縮で物を落とすことがある。
- 若年ミオクロニーてんかんは起床時、睡眠不足、光刺激が手掛かりになる。

## 発作時の対応

- 周囲の危険物を除き、頭部を保護する。
- 発作の開始時刻、持続時間、身体部位、意識状態を観察する。
- 無理に押さえつけない。
- 口の中に物や指を入れない。
- 意識が戻らない、発作が長い、反復する、外傷がある場合は緊急対応する。
- 焦点意識減損発作で歩き回る場合は、安全を確保して静かに見守る。

## 睡眠障害

| 疾患 | 特徴 |
|---|---|
| ナルコレプシー | 日中の耐え難い眠気、情動脱力発作、睡眠麻痺、入眠時幻覚 |
| 睡眠相後退 | 入眠・起床時刻が遅れ、望む時刻に寝起きできない |
| REM睡眠行動障害 | 夢の内容に合わせた大きな行動。Lewy小体病と関連 |
| 睡眠時無呼吸 | いびき、無呼吸、日中の眠気 |
| むずむず脚症候群 | 安静時の不快感と脚を動かしたい衝動。鉄欠乏と関連 |

- 睡眠日誌は睡眠・覚醒時刻のパターン把握に向き、睡眠相後退の評価に有用である。
- 情動による突然の脱力はナルコレプシーの情動脱力発作を考える。

## 睡眠衛生

- 起床時刻をできるだけ一定にする。
- 眠くないのに長時間寝床にいない。
- 就寝前のアルコールを睡眠薬代わりにしない。
- 夕方以降の長い昼寝を避ける。
- 朝の光を利用し、日中に適度な活動を行う。

## 国試のひっかけ

- すべてのてんかん発作で意識が失われるわけではない。
- 発作中の患者を強く制止しない。
- REM睡眠行動障害は単なる悪夢ではない。
- アルコールは寝つきを良くしても睡眠の質を悪化させる。

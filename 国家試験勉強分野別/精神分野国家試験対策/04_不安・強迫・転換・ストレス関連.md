# 不安・強迫・転換・ストレス関連

## 強迫症

- 強迫観念は、繰り返し浮かぶ不快な考え、衝動、イメージである。
- 強迫行為は、不安を下げるために繰り返す確認、洗浄、数え直し、儀式などである。
- 多くの患者は、不合理・過剰だと分かっていても止めにくい。
- 強迫行為を行うと一時的に不安が下がるため、行為が強化される。
- 代表的治療は認知行動療法の**曝露反応妨害法**である。
- 曝露反応妨害法では、不安を生む刺激に触れ、強迫行為を行わずに待つ。

## 不安症の見分け方

| 疾患 | 特徴 |
|---|---|
| パニック症 | 突然の強い不安発作と再発への予期不安 |
| 広場恐怖 | 逃げにくい、助けを得にくい場所を恐れて回避する |
| 社交不安症 | 他人から評価される場面を強く恐れる |
| 全般不安症 | 複数の出来事への過剰な心配が長く続く |
| 限局性恐怖 | 特定の対象・状況への強い恐怖 |

## PTSDと適応障害

- PTSDは生命・身体への重大な脅威となる出来事の後に生じる。
- 侵入症状、回避、認知・気分の変化、過覚醒を整理する。
- 適応障害では、確認できるストレス因に反応して抑うつや不安が生じる。
- 適応障害では環境調整、心理療法、コーピング支援が中心になる。
- 適応障害で薬物療法だけを治療の中心と考えない。

## 転換・解離・身体症状

- 機能性神経症状症・変換症では、既知の神経疾患だけでは説明できない運動・感覚症状がみられる。
- 症状を意図的に作っていると決めつけない。
- 診断を理解し受け入れられることは予後に良い影響を与える。
- 解離症では記憶、同一性、意識、知覚のまとまりが途切れる。
- 離人感は、自分が自分でないように感じる体験である。
- 心気的な訴えは、病気への強いとらわれが中心になる。

## 心理療法

- 系統的脱感作法は、不安階層表とリラクセーションを用いる。
- 曝露療法は、恐れている刺激や状況を安全に体験する。
- 認知行動療法は認知と行動の悪循環を修正する。
- 森田療法では症状を無理に消そうとせず、目的に沿って行動する。入院療法の初期に絶対臥褥を行う。

## 国試のひっかけ

- 強迫症は強迫観念だけでなく、強迫行為との悪循環を理解する。
- 強迫症の治療は単なるリラクセーションではなく曝露反応妨害法が中心である。
- 適応障害は日常生活に支障を来し得る。
- 転換症は詐病と同じではない。

## 直前チェック

- 強迫症＝曝露反応妨害法
- 系統的脱感作＝不安階層表
- PTSD＝侵入・回避・陰性変化・過覚醒
- 適応障害＝明確なストレス因
- 転換症＝意図的に作った症状とは限らない

# 精神科治療・地域支援・患者対応

## 精神療法の対応

| 方法 | 覚えるポイント |
|---|---|
| 認知行動療法 | 認知と行動の悪循環を修正。ホームワークを用いる |
| 曝露反応妨害法 | 強迫症で、曝露後の強迫行為を止める |
| 系統的脱感作法 | 不安階層表とリラクセーション |
| 精神分析療法 | 自由連想、無意識の葛藤、転移の解釈 |
| 森田療法 | 症状をあるがまま受け入れ、目的に沿って行動。絶対臥褥 |
| 内観療法 | してもらったこと、して返したこと、迷惑をかけたことを振り返る |
| 自律訓練法 | 自己暗示で心身をリラックスさせる |
| SST | モデリング、ロールプレイ、フィードバックで生活技能を練習 |

## 薬物療法

- 抗精神病薬は統合失調症などに用いる。錐体外路症状、悪性症候群、代謝異常に注意する。
- 抗うつ薬は効果発現まで時間がかかる。開始直後から十分に効くとは限らない。
- 気分安定薬は双極性障害で用いる。
- ベンゾジアゼピン系薬は依存、転倒、運動失調、健忘に注意する。
- 服薬を自己判断で突然中止させない。

## 電気けいれん療法

- 重症うつ病、強い希死念慮、昏迷、緊張病などで検討される。
- 現在は麻酔薬と筋弛緩薬を用いる修正型が中心である。
- 一時的な記憶障害などに注意する。

## ACTと地域支援

- ACTは包括型地域生活支援である。
- 重い精神障害がある人を、多職種チームが地域で支援する。
- 短時間でも頻回に訪問する。
- ケアマネジメントをチームで共有する。
- 夜間・休日を含む危機対応を重視する。
- スタッフ1人当たりの担当人数を少なくする。

## 心理教育と家族支援

- 本人と家族が疾患、治療、薬、再発徴候、対処法を学ぶ。
- 統合失調症では高EEへの家族支援が再発予防につながる。
- 依存症では家族のイネイブリングを理解し、家族も支援する。
- 病気を本人の責任として非難しない。

## 患者への基本対応

- まず患者の言葉を遮らずに聴く。
- 感情を否定せず、「心配なのですね」と受け止める。
- 根拠のない安心を与えない。
- 妄想の内容に同意はしないが、体験している苦痛は受け止める。
- 患者の理解力に合わせて、短く具体的に説明する。
- 自己決定を尊重しつつ、自傷・他害・転倒などの安全を確保する。
- 薬の副作用や中止希望は主治医・チームへ共有する。

## 障害受容

- ショック、否認、混乱、適応などは一直線に進むとは限らない。
- 怒りが医療者に向くことがある。
- 同じ障害がある人との交流が受容を助けることがある。
- 抑うつが強い時期に積極的な指導を押しつけない。

## 国試のひっかけ

- ACTは軽症者だけを対象にした日中限定サービスではない。
- 精神療法の名称と技法を入れ替えた選択肢に注意する。
- 共感は「大丈夫」と断言することではない。
- 妄想を強く否定して論破しようとしない。

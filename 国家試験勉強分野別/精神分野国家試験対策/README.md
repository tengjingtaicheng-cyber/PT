- Alzheimer型認知症とLewy小体型認知症の違い

- 統合失調症の陽性症状・陰性症状・自我障害
- 強迫症と曝露反応妨害法

- てんかん発作の分類と発作時対応
- 心理検査の分類と測定対象
- 記憶の分類
- 防衛機制とEriksonの発達課題

# パーソナリティ障害

## 基本

- 考え方、感情、対人関係、衝動コントロールの持続的な偏りが、本人や周囲の生活に問題を生じさせる。
- 一時的な症状ではなく、青年期・成人早期から多くの場面で続くパターンとして捉える。
- 性格が悪いという意味ではない。

## 頻出の見分け方

| 型 | 重要な特徴 |
|---|---|
| 境界性 | 見捨てられ不安、不安定な対人関係、感情不安定、衝動性、自傷 |
| 妄想性 | 他者への広範な不信と疑い |
| 統合失調型 | 奇異な信念・知覚、風変わりな行動、親密な関係の乏しさ |
| 依存性 | 世話を受けたい強い欲求、分離への恐れ、自己決定の困難 |
| 回避性 | 否定的評価への過敏さ、対人関係への強い抑制 |
| 反社会性 | 他者の権利を軽視し、規範違反を繰り返す |
| 強迫性 | 秩序、完璧主義、統制へのこだわり。強迫症とは別概念 |

## 境界性で特に覚える

- 見捨てられることを避けようと必死になる。
- 相手を理想化した直後にこき下ろすなど、評価が極端に変わる。
- 自傷や自殺企図、衝動行為がみられることがある。
- 慢性的な空虚感や強い怒りを伴うことがある。

## 国試のひっかけ

- 「奇異な考えと風変わりな行動」は統合失調型を考える。
- 統合失調型パーソナリティ障害は統合失調症そのものではない。
- 強迫性パーソナリティ障害では、本人が価値ある習慣と感じている場合がある。強迫症では、強迫観念や行為を苦痛と感じることが多い。
- 見捨てられ不安は境界性の代表的特徴である。

## 直前チェック

- 境界性＝見捨てられ不安
- 妄想性＝不信・疑い
- 統合失調型＝奇異・風変わり
- 依存性＝自己決定困難・分離不安
- 回避性＝否定的評価への過敏さ

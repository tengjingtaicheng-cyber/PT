# 心理検査・認知機能・記憶

## 検査法の分類

### 質問紙法

- BDI-IIは抑うつ症状を評価する。
- STAIは状態不安と特性不安を評価する。
- MMPIは人格を多面的に評価する。
- CMIは心身の自覚症状を質問紙で調べる。

### 投影法

- Rorschachテストは左右対称のインクのしみを用いる。
- TATは絵から物語を作らせる。
- 文章完成法は未完成の文章を完成させる。
- バウムテストは木を描かせる。

### 作業検査法

- 内田クレペリン精神検査は連続加算作業を用いる。

## 症状評価と認知評価を区別する

| 検査 | 主な対象 |
|---|---|
| HDS-R | 認知症スクリーニング |
| MMSE | 認知機能スクリーニング |
| WAIS | 成人の知能 |
| WMS-R | 記憶機能 |
| RBMT | 日常生活に近い記憶 |
| BADS | 遂行機能 |
| BDI-II | 抑うつ症状 |
| BPRS | 精神症状全般 |
| PANSS | 統合失調症の陽性・陰性症状など |
| HAM-D | うつ病の重症度を評価者が判定 |

- BDI-IIは自己記入式である。
- HAM-D、BPRS、PANSSは評価者が面接・観察して評価する。
- WAISは人格検査ではない。
- MMSEは人格検査ではない。
- STAIとCMIは第61回で複数正答として扱われたため、分類の幅に注意する。

## 記憶の分類

| 分類 | 内容 |
|---|---|
| エピソード記憶 | 個人的な出来事の記憶 |
| 意味記憶 | 言葉や一般知識の記憶 |
| 手続き記憶 | 技能や習慣の記憶 |
| 作動記憶 | 情報を一時保持しながら処理する |
| 展望記憶 | 将来行う予定を覚えて実行する |
| プライミング | 以前の刺激が無意識に後の反応へ影響する |

- エピソード記憶と意味記憶は陳述記憶である。
- 手続き記憶とプライミングは非陳述・潜在記憶である。
- 「ベルが鳴ったら訓練を終える」「翌朝の会議を思い出す」は展望記憶である。
- 自動販売機の手順そのものは手続き記憶だが、つり銭を確認する判断には明示的な知識が関わる。

## 国試のひっかけ

- 検査名を見たら「方法」「測る対象」「自己記入か評価者記入か」を分けて考える。
- 投影法と質問紙法を混同しない。
- 記憶検査と知能検査を混同しない。
- プライミングを陳述記憶に入れない。

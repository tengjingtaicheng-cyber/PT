# 心理学基礎・発達理論・防衛機制

## 防衛機制

| 名称 | 意味 | 典型例 |
|---|---|---|
| 抑圧 | 受け入れ難い内容を無意識へ押し込める | 苦痛な記憶を意識できない |
| 抑制 | 不快な考えを意識的に考えないようにする | 今は考えず後で対処する |
| 投影 | 自分の感情を他人のものとみなす | 自分の敵意を「相手が敵意を持つ」と感じる |
| 反動形成 | 本来の欲求と反対の態度をとる | 嫌いな相手へ過度に親切にする |
| 置き換え | 感情を安全な別対象へ向ける | 上司への怒りを家族へ向ける |
| 昇華 | 衝動を社会的に価値ある活動へ向ける | 攻撃性や性欲をスポーツへ向ける |
| 合理化 | 本当の動機を隠す理由を作る | 失敗を「価値がないから」と説明する |
| 同一化 | 他者の特徴を自分へ取り入れる | 憧れの人の口調をまねる |
| 知性化 | 感情から距離を置いて理論的に扱う | 不安な問題を分析だけで処理する |
| 退行 | より幼い段階の行動へ戻る | 強い不安で甘えた行動をとる |

- 第59回の抑圧と抑制を問う設問は、問題文が不明確で複数正答に訂正された。両者の「無意識」と「意識的」の違いを理解する。

## Eriksonの発達課題

| 時期 | 課題 |
|---|---|
| 乳児期 | 基本的信頼 対 不信 |
| 幼児前期 | 自律性 対 恥・疑惑 |
| 遊戯期 | 自発性 対 罪悪感 |
| 学童期 | 勤勉性 対 劣等感 |
| 青年期 | 同一性 対 同一性拡散 |
| 成人前期 | 親密性 対 孤立 |
| 成人期 | 生殖性 対 停滞 |
| 老年期 | 統合性 対 絶望 |

- 幼児期と幼児前期の表記差に注意し、年齢と課題を対応させる。
- 学童期は勤勉性、青年期は自我同一性、成人前期は親密性、老年期は統合性である。

## 学習理論

- 古典的条件付けは、刺激と刺激の結び付きで反応が形成される。
- オペラント条件付けは、行動の結果によって行動頻度が変化する。
- 正の強化は、好ましい刺激を加えて行動を増やす。
- 負の強化は、不快な刺激がなくなることで行動を増やす。
- 罰は行動を減らす。負の強化と同じではない。
- モデリングは、他者の行動を観察して学ぶ。

## 精神分析の基本

- Freudは無意識、精神分析、自由連想と関係する。
- Jungは個人的無意識に加えて集合的無意識を提唱した。
- Adlerは劣等感や個人心理学と関係する。
- 転移は、過去の重要人物への感情を治療者へ向けることをいう。
- 逆転移は、治療者が患者へ向ける感情反応である。
- 患者が治療者へ好意を向けるのは陽性転移である。

## 障害受容

- ショック、否認、怒り・混乱、適応などの反応がみられる。
- 段階は必ず一定方向に進むとは限らない。
- 社会環境や同じ障害がある人との交流が影響する。
- 怒りが医療者へ向くことがある。

## 国試のひっかけ

- 抑圧は無意識、抑制は意識的である。
- 昇華と置き換えを混同しない。社会的価値ある活動へ向けるのが昇華である。
- 負の強化は罰ではない。行動を増やす。
- 転移は患者側、逆転移は治療者側の反応として整理する。

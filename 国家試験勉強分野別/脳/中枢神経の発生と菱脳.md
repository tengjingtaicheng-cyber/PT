# 中枢神経の発生と菱脳

胎児の**神経管**の頭側が膨らみ、まず3つの**一次脳胞**ができる。

## 発生の流れ

| 一次脳胞 | 二次脳胞 | 成人での主な構造 |
|---|---|---|
| **前脳** | **終脳** | 大脳半球・大脳皮質・大脳基底核・海馬など |
| **前脳** | **間脳** | 視床・視床下部・網膜など |
| **中脳** | **中脳** | 中脳 |
| **菱脳** | **後脳** | **橋・小脳** |
| **菱脳** | **髄脳** | **延髄** |

## 菱脳とは

- **菱脳は、橋・小脳・延髄のもとになる部分**である。
- 菱脳は、発生の途中で**後脳と髄脳**に分かれる。
- **後脳 → 橋・小脳**
- **髄脳 → 延髄**
- 菱脳の内腔は、主に**第四脳室**になる。

## 最重要

**菱脳 → 後脳＋髄脳 → 橋・小脳＋延髄**

## 覚え方

- **「後ろに橋と小脳、髄には延髄」**
- **「菱形の部屋（第四脳室）に、橋・小脳・延髄」**

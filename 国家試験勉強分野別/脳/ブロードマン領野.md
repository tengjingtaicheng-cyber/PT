# ブロードマン領野の対応

ブロードマン領野は、大脳皮質を**細胞構築の違い**によって番号分けしたものである。

| 領野 | 名称 | 主な働き |
|---:|---|---|
| **1・2・3** | 一次体性感覚野 | 触覚・痛覚・温度覚・深部感覚 |
| **4** | 一次運動野 | 随意運動の実行 |
| **5・7** | 体性感覚連合野 | 感覚の統合・物体の認識 |
| **6** | 運動前野・補足運動野 | 運動の計画・準備 |
| **8** | 前頭眼野 | 随意的な眼球運動 |
| **9～12** | 前頭前野 | 判断・計画・意思決定など |
| **17** | 一次視覚野 | 視覚情報を受け取る |
| **18・19** | 視覚連合野 | 見た物の意味を認識する |
| **22** | ウェルニッケ野（優位半球後部） | 言葉を理解する |
| **39** | 角回 | 読字・書字・言語理解 |
| **40** | 縁上回 | 言語・感覚情報の統合 |
| **41・42** | 聴覚野 | 41：一次聴覚野、42：聴覚連合野 |
| **43** | 味覚野 | 味覚 |
| **44・45** | ブローカ野（優位半球） | 発語・言語表出 |

## 特に重要な対応

- **1・2・3＝感覚**
- **4＝運動**
- **17＝視覚**
- **22＝ウェルニッケ野**
- **41・42＝聴覚**
- **44・45＝ブローカ野**

## 覚え方

- **「感覚いち・に・さん、運動し（4）よう」**  
  → 1・2・3は体性感覚野、4は運動野
- **「いいな（17）、見える」**  
  → 17は一次視覚野
- **「夫婦（22）は話を理解する」**  
  → 22はウェルニッケ野
- **「よい耳（41・42）」**  
  → 41・42は聴覚野
- **「獅子（44・45）がしゃべる」**  
  → 44・45はブローカ野

> ブローカ野は主に**44・45野**、ウェルニッケ野は古典的には主に**22野**を指す。現代では、言語機能は39・40野などを含む広いネットワークで担われると考えられている。

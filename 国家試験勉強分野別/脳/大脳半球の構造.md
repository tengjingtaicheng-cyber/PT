# 大脳半球に含まれる主な構造

- 大脳半球には、**大脳皮質・大脳白質・大脳基底核・側脳室**がある。
- 大脳皮質には、**前頭葉・頭頂葉・側頭葉・後頭葉・島葉・辺縁葉**がある。
- 広義の大脳基底核には、**尾状核・被殻・淡蒼球・前障・扁桃体**がある。
  - 運動系の大脳基底核としては、主に**尾状核・被殻・淡蒼球**を扱う。
  - **扁桃体**は、機能的には主に**大脳辺縁系**として扱う。
  - **被殻＋淡蒼球＝レンズ核**
  - **尾状核＋被殻＝線条体**
- 大脳白質には、**脳梁・内包・放線冠・脳弓・前交連**などがある。
- 辺縁系には、**帯状回・海馬・海馬傍回・扁桃体**などがある。

## 語呂

- 広義の基底核：**「尾っぽに被せた淡い前掛け、桃色」**  
  → **尾**状核・**被**殻・**淡**蒼球・**前**障・扁**桃**体
- 白質：**「脳内、放課後に前へ」**  
  → **脳**梁・**内**包・**放**線冠・**弓**（放課後の「後」で連想）・**前**交連

> 注意：視床・視床下部は大脳半球ではなく、**間脳**に含まれる。

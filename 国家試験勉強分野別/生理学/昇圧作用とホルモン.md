# 昇圧作用とホルモン

## 昇圧作用とは

**昇圧作用とは、血圧を上げる働きのことです。**

血管を収縮させる、心臓の拍動を強める、または体内の水分・循環血液量を増やすことで血圧が上昇します。

> 血圧 ＝ 心拍出量 × 末梢血管抵抗

## 昇圧作用を持つ主なホルモン

| ホルモン | 主な昇圧作用 |
|---|---|
| **アドレナリン** | 心拍数と心収縮力を高め、心拍出量を増やす |
| **ノルアドレナリン** | 末梢血管を収縮させ、末梢血管抵抗を高める |
| **アンジオテンシンⅡ** | 強力に血管を収縮させ、アルドステロンやバソプレシンの分泌も促す |
| **バソプレシン（ADH）** | 血管を収縮させ、腎臓の集合管で水の再吸収を促す |
| **アルドステロン** | Na⁺の再吸収を促し、それに伴って水分と循環血液量を増やす |
| **コルチゾール** | カテコールアミンの作用を保ち、過剰時にはNa⁺・水分貯留にも関係する |

特に代表的な昇圧ホルモンは、**カテコールアミン（アドレナリン・ノルアドレナリン）、アンジオテンシンⅡ、バソプレシン**です。[日本内科学会「内分泌性高血圧症」](https://www.jstage.jst.go.jp/article/naika/95/4/95_4_616/_pdf)

### レニンについて

レニンは、アンジオテンシンⅡを生じさせるRAA系を始動し、**間接的に血圧を上げます**。レニン自体が血管を直接収縮させるわけではありません。

## 覚え方

### 外部で紹介されている語呂

**「アル・バゾ・神（あるばぞしん）」**

- **アル**：アルドステロン
- **バゾ**：バソプレシン
- **神**：心房性Na利尿ペプチド（ANP）

これは「血液量を調節するホルモン」の語呂として国試黒本で紹介されています。[国試黒本「血液量を調節するホルモンの語呂合わせ」](https://kurohon.jp/gakusei/goro/100/)

> 注意：アルドステロンとバソプレシンは血液量を増やして昇圧方向に働きますが、**ANPはNa⁺と水の排泄を促し、血圧を下げる方向に働きます。**

バソプレシンは、英語の **vaso（血管）＋ press（圧迫する）** と結び付けると、血管収縮と昇圧作用を覚えやすくなります。[バソプレシンの覚え方と国試問題](https://ahq-study.com/riyutoku/study/kango/110P083.html)

### 昇圧ホルモンの補助的な語呂（オリジナル）

**「圧を上げる、カ・アン・バ」**

- **カ**：カテコールアミン
- **アン**：アンジオテンシンⅡ
- **バ**：バソプレシン

まずこの3つを代表的な昇圧ホルモンとして覚え、体液量を増やす**アルドステロン**と、昇圧作用を支える**コルチゾール**を追加します。

## 最低限のまとめ

> **血管収縮はノルアドレナリン・アンジオテンシンⅡ・バソプレシン、心拍出量増加はアドレナリン、体液量増加はアルドステロン・バソプレシン。**

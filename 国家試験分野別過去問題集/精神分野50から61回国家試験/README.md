## 範囲上の注意

- 「精神分野」は、精神医学と臨床心理学に加え、明示的な認知症関連問題を含めた。
- 神経内科学のみを問う問題、精神症状と無関係な高齢者一般、PT専門問題の身体疾患は除外した。
- 第61回は公開直後で検索DBへの収載が未完了だったため、問題PDFと厚労省正答表から直接確認した。
- 疾患横断の組合せ問題は、主題が単一疾患に決められないため「精神医学・臨床心理学横断」に収録した。

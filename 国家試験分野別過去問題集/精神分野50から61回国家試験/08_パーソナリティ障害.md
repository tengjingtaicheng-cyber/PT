# パーソナリティ障害｜第50〜61回 理学療法士国家試験

> 境界性、妄想性、依存性、統合失調型などを、対人関係・感情・認知・衝動性の特徴で見分ける。名称の似た統合失調症とは区別する。

収録数：**5問**

※問題文・選択肢は公開資料と検索用DBで照合。学習用資料であり、診療判断には使用しないこと。

## 第50回 午後 第99問

**問題**：パーソナリティ障害と特徴の組合せで正しいのはどれか。

1. 依存性パーソナリティ障害 － 嗜癖
2. 演技性パーソナリティ障害 － 被暗示性
3. 回避性パーソナリティ障害 － 冷淡
4. 統合失調質パーソナリティ障害 － 攻撃性
5. 非社会性パーソナリティ障害 － 几帳面

**正答**：2

**確認ポイント**：正答として問われた内容は「演技性パーソナリティ障害 － 被暗示性」。この特徴・組合せを基準に、他の選択肢との違いを整理する。

## 第52回 午後 第98問

**問題**：境界性パーソナリティ障害にみられないのはどれか。

1. 不安定な感情
2. 孤立への欲求
3. 持続的な空虚感
4. 不明瞭な自己像
5. 繰り返す自傷行為

**正答**：2

**確認ポイント**：正答として問われた内容は「孤立への欲求」。設問は誤り・非該当を選ぶ形式。この選択肢のどこが誤りかを、他の選択肢と対比して覚える。
